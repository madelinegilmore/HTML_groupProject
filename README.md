# Endangered Animal Conservation Web Project

## Overview

**Endangered Animal Conservation** is a collaborative educational web project that raises awareness about endangered species and conservation efforts. Developed by the IDEAL team as a group project, this website provides comprehensive information about endangered animals, the causes of their endangerment, global conservation efforts, and inspiring success stories.

## Project Purpose

This website aims to:
- Educate visitors about endangered animal species and extinction risks
- Explain the causes of animal endangerment (habitat destruction, climate change, human activity)
- Showcase conservation efforts and organizations working to protect endangered species
- Highlight success stories of species recovery
- Provide an interactive platform for user engagement and feedback

## Features

- **Home Page**: Featured exploration cards linking to key conservation topics
- **Endangered Species Gallery**: Visual showcase of animals at risk of extinction
- **Educational Content Pages**: Detailed information on:
  - Causes of animal endangerment
  - Endangered species profiles
  - Active conservation efforts
  - Species recovery success stories
- **User Profile Page**: For visitors to personalize their experience
- **Action Impact Simulator**: Interactive tool to explore the effects of conservation actions
- **Feedback System**: Allows users to share thoughts and suggestions
- **Team Information**: Credits and team member details
- **Responsive Design**: Clean, modern interface with CSS styling

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/madelinegilmore/HTML_groupProject.git
   cd HTML_groupProject
   ```

2. Open the project in your browser:
   - Open `home.html` in your web browser to view the website
   - Or use a local server for better experience

3. **Important**: Before committing changes, always pull the latest version:
   ```bash
   git pull
   ```
